A lightning-fast, keyboard-centric new tab page for power users. This project is a feature-rich fork of the **Humble New Tab Page** extension, with added functionalities and optimized for productivity.

## Features & Roadmap

- [x] **Vim Navigation** — Navigate your bookmarks and links seamlessly using intuitive keyboard shortcuts.
- [ ] **Theme Picker** — Switch instantly between popular aesthetic themes (Nord, Catppuccin, Rosé Pine, Tokyo Night, and more).
- [ ] **Cut, Copy & Paste for Bookmarks** — Easily rearrange and reorganize your bookmarked links directly from the keyboard or mouse.

## Usage & Navigation

Designed with speed in mind, OhMyNewTabPage allows you to stay entirely* on your keyboard.

| **Key**                  | **Action**                                 |
| :----------------------- | :----------------------------------------- |
| `h` or `left arrow (←)`  | Select the node on the column to the left  |
| `l` or `right arrow (→)` | Select the node on the column to the right |
| `j` or `down arrow (↓)`  | Select the node on the next row            |
| `k` or `up arrow (↑)`    | Select the node on the previous row        |
| `Enter` or `o`           | Open folder or link                        |

*The options menu navigation is a work in progress.
